# Paddy小助手

周鹏（Paddy）和白敏的周末活动组织小程序：家宴聚餐、户外活动、团体活动、周边旅行，一站式发起、报名、筹备。

## 如何打开项目

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → 导入项目 → 选择本文件夹（`Paddy小助手`）
3. AppID 已配置为 `wx0000000000000000`，选择"使用已注册的 AppID"即可
4. 点击"编译"，即可在模拟器中体验

## 云开发（登录已接入）

本项目已开通微信云开发，环境 ID：`your-cloud-env-id`

首次使用前，需要做三步部署：

1. 在开发者工具中右键 `cloudfunctions/login` 文件夹 → 上传并部署：云端安装依赖
2. 右键 `cloudfunctions/activity` 文件夹 → 上传并部署：云端安装依赖
3. 打开云开发控制台 → 数据库 → 新建集合 `users` 和 `activities`（权限保持默认即可）

登录时会把微信头像（上传到云存储）、昵称、位置保存到 `users` 集合，每个微信用户有唯一的身份（openid）。
活动数据通过 `activity` 云函数同步到 `activities` 集合：本地操作自动推送，进入首页自动拉取，朋友们就能看到彼此的活动和操作。
云环境不可用时（比如还没部署云函数），登录会自动退回本地模式，不影响其他功能。

## 上线前检查清单

1. **部署全部云函数**：`login`、`activity`、`weather` 三个文件夹都右键 → 上传并部署：云端安装依赖
2. **创建集合**：云开发控制台 → 数据库 → 新建 `users`、`activities`、`circles`（`circles` 也可由云函数自动创建）
3. **配置隐私保护指引**：mp.weixin.qq.com → 设置 → 服务内容声明 → 用户隐私保护指引，声明使用的接口：
   - 位置信息（`chooseLocation`，地图选点）
   - 相册（上传照片）
   - 摄像头（拍照上传）
   - 微信头像昵称（登录）
4. **真机测试**：开发者工具表现 ≠ 真机，SVG 图标、毛玻璃、地图、选头像需在 iOS 和 Android 真机预览验证
5. **类目匹配**：确认小程序注册类目与功能一致（建议“工具-效率”类）
6. **内容安全（已接入文本校验）**：活动标题、介绍、留言、昵称在保存到云端前都会经过微信内容安全接口校验，命中风险内容直接拒绝保存（接口不可用时自动放行，不影响正常使用）；相册照片为好友间私有内容，暂未接入异步图片审核

## 圈子（隐私与隔离）

小程序按「圈子」组织：每个人可以创建自己的圈子，创建时系统**自动生成 8 位随机通行码**（避开易混淆字符），朋友凭这个码加入。圈子之间完全隔离：

- 活动、成员资料、通知都只在圈子内部可见，其他圈子的人看不到
- 云端会校验请求者是否真的是当前圈子成员，不是成员一律拒绝（不是只靠前端隐藏）
- 一个人可以加入多个圈子，在「我的 → 我的圈子」里切换；首页会显示当前圈子名
- 首次创建/加入圈子时，本地已有活动会自动归属到该圈子
- 通行码自动生成且不重复，用户无法自定义，从源头避免“1234”这类简单码导致的偶然相遇

第一次打开小程序会先进「圈子」页（创建或加入），之后才能看到活动。创建成功后弹窗展示通行码，可直接复制发给朋友。

## 订阅消息（好友活动通知，可选）

微信规定：小程序不能主动给用户发通知，必须先由用户**授权一次订阅**，且一次授权只能发一条消息。

启用步骤：

1. 登录 mp.weixin.qq.com → 订阅消息 → 公共模板库 → 搜索「活动提醒」类模板 → 选用一个（记下模板 ID 和字段名）
2. 把模板 ID 填入两处：
   - `miniprogram/utils/config.js` 的 `SUBSCRIBE_TEMPLATE_ID`
   - `cloudfunctions/activity/index.js` 顶部的 `SUBSCRIBE_TEMPLATE_ID`
3. 云函数 `activity` 里的模板字段 key（`thing1`/`time2`/`thing3`）需要与所选模板的字段名一致，在模板详情页核对后修改
4. 右键 `cloudfunctions/activity` → 上传并部署：云端安装依赖

效果：好友登录时会被询问是否允许接收通知；允许后，你每创建一个新活动，云端就会给已授权的好友推一条「新活动提醒」，点开直达活动详情。模板 ID 留空时该功能自动停用，不影响其他功能。

## AI 助手（可选）

四个 AI 功能：创建活动时「AI 帮我想」（标题/文案/私房菜单）、旅行页「AI 生成行程」、团体页「AI 推荐玩法」、详情页「AI 活动小记」。

启用步骤：

1. 注册智谱开放平台（open.bigmodel.cn）→ 实名认证 → 创建 API Key（glm-4-flash 很便宜）；想用 DeepSeek 就去 platform.deepseek.com
2. 打开 `cloudfunctions/ai/index.js`，把 `AI_KEY` 填成你的 Key；用 DeepSeek 就把 `AI_BASE`/`AI_MODEL` 换成文件里的注释示例
3. 右键 `cloudfunctions/ai` → 上传并部署：云端安装依赖
4. 云开发控制台 → 云函数 → `ai` → 配置 → 把超时时间调到 60 秒（AI 生成需要几秒到二十秒）
5. 重新编译

说明：AI 调用按次计费（每次约几厘到几分钱），未配置 Key 时页面按钮会提示“AI 尚未配置”，不影响其他功能。生成的内容在保存活动时会经过内容安全校验。

## 当前版本（v0.9）

- 首页：下一场活动 + 近期活动列表 + 快捷发起
- 发起活动：选择类型（聚餐/户外/团体活动/旅行）、填时间地点、邀请好友
- 活动详情：报名（参加/待定/不参加）、成员名单、留言区
- 聚餐筹备：时间投票、点菜、带菜登记、自动生成采购清单
- 户外筹备：拼车统计与自动安排座位、装备清单、天气与出行提醒
- 地图选点：活动、好友、我的位置都可以在地图上点选；详情页点地址直接打开地图
- 团体活动筹备：按参加者位置自动计算居中地点并在地图上展示、候选场馆投票与选定
- 旅行筹备：多日行程规划、分工认领、住宿登记、AA 预算记账
- 微信登录：使用微信头像和昵称登录（个人资料设置）
- 活动管理：个人侧的删除管理，不影响共享数据
- 好友管理：微信风格的好友列表，可添加（含头像选择）、删除、改位置
- 好友自动同步：登录过小程序的朋友会自动出现在好友列表（微信头像昵称），手动添加的好友登录后自动绑定真实账号；删除仅在个人端生效
- 圈子隔离：创建/加入圈子后，活动与成员只在圈内可见，云端强制校验成员身份
- 活动相册：任何活动都能匿名上传照片，大家点赞/点踩，前三名自动带奖牌
- 活动数据上云：登录后活动自动同步到云端，所有朋友看到同一个活动列表，报名/投票/相册实时共享
- 活动列表：进行中 / 已结束
- 好友圈：好友列表、添加、修改位置、删除
- 我的：个人信息、我的位置、我参加的活动

数据目前保存在本地（手机/模拟器上），方便先跑通流程。下一阶段接入微信云开发后，所有朋友的数据可以实时同步。

> 天气提示：开发调试时可直接使用；正式发布前需要把 `wttr.in` 加入小程序的 request 合法域名（或在云函数中转发）。
