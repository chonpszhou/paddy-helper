# Paddy小助手

> 和朋友们一起，把每个周末过得热气腾腾 🔥

Paddy小助手是周鹏（Paddy）和白敏为朋友们的周末生活做的小程序：家宴聚餐、户外徒步、桌游聚会、周边旅行，从**发起 → 报名 → 筹备 → 分享**一站式搞定。

- 技术形态：微信原生小程序 + 微信云开发（云函数 / 云数据库 / 云存储）
- AppID：`wx0000000000000000`
- 云环境：`your-cloud-env-id`
- 当前状态：**已通过功能开发，准备提审发布（v1.0.0）**

## 🚀 快速开始

### 1. 打开项目

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入项目 → 选择本目录，AppID 使用已注册的 `wx0000000000000000`
3. 建议在「详情 → 本地设置」中把**调试基础库切到稳定版**（不要用灰度版，灰度版有渲染层 bug 会导致按钮点击无响应）
4. 点击「编译」即可体验

### 2. 部署云函数

在开发者工具中，依次对以下目录**右键 → 上传并部署：云端安装依赖**：

| 云函数 | 说明 |
| --- | --- |
| `login` | 登录、用户资料、圈子创建/加入/退出/解散、圈子成员列表 |
| `activity` | 活动云端同步、圈子成员校验、订阅消息推送、内容安全 |
| `ai` | AI 文案生成 + AI 生图海报（依赖 `wx-server-sdk ^4.0.2`） |
| `weather` | 天气查询（服务端转发，避免生产环境域名限制） |

### 3. 数据库集合

云开发控制台 → 数据库，创建：

- `users`：用户资料（昵称/头像/位置/订阅状态）
- `activities`：活动数据（含筹备、相册等全部内容）
- `circles`：圈子（可由云函数自动创建，也可手动新建）

权限保持默认即可（所有读写都走云函数，由云端校验成员身份）。

### 4. 云函数配置项

- **ai 云函数超时时间调到 300 秒**（生图较慢），并在云开发控制台开启「AI → 生图模型」
- 订阅消息模板 ID 已填入 `miniprogram/utils/config.js` 与 `cloudfunctions/activity/index.js`，字段为 `thing1 / time2 / thing3`

## 🛡️ 圈子：隐私与隔离

- 任何人可创建圈子，系统**自动生成 8 位随机通行码**（避开 0/O/1/I/L 等易混淆字符），朋友凭码加入
- 圈子之间完全隔离：活动、成员资料、通知只在圈内可见
- **云端强制校验**：不是圈子成员，云函数一律拒绝访问（不是只靠前端隐藏）
- 一人可加多个圈子，「我的 → 我的圈子」随时切换；**通行码常驻显示，可一键复制**发给新朋友
- 可随时**退出圈子**（自己离开，不影响他人）；创建者可**解散圈子**（删除圈内全部数据，不可恢复）
- 换手机/新设备登录后，圈子列表会从云端自动同步

## 🍲 聚餐与私房菜

发起聚餐时可选择：

- **家里聚餐**：时间投票 + 点菜 + 带菜登记 + 自动生成采购清单（没人带的菜会自动进入清单）
- **餐厅聚餐**：只保留时间投票，省去点菜、带菜与采购

当聚餐地点包含「周鹏家 / Paddy家」时，自动解锁隐藏彩蛋 **「周鹏私房菜」**：50 道北方风味菜单，包括：

- 鄂尔多斯蒙式：阿尔巴斯风干羊肉、手扒肉、烤羊排、蒙古奶茶……
- 巴彦淖尔河套：巴盟烩酸菜、猪肉勾鸡、河套铁锅焖面、油烙饼……
- 东北硬菜：锅包肉、杀猪菜、小鸡炖蘑菇、铁锅炖大鹅……

菜单可一键加入点菜清单，大家直接在筹备页点菜投票。

## 🎨 海报与 AI

### 活动海报

详情页 →「📸 海报」，一键生成长图海报（标题/时间/地点/参加者/圈子名），支持保存相册与分享，朋友点开直达活动详情。

### AI 生图背景

海报页可选「✨ AI 风格海报」：极光 / 山野 / 美食 / 星空四个预设，或自定义一句话描述。AI 生成的背景图会转存到云存储（永久有效），文字仍由本地画布排版，保证清晰。

### AI 文案助手（四个入口）

| 入口 | 功能 |
| --- | --- |
| 发起活动页「✨ AI 帮我想」 | 一句话主题，生成标题、邀请文案、菜单与准备建议 |
| 旅行筹备「✨ AI 生成行程」 | 输入目的地和天数，生成每日行程与预算 |
| 团体筹备「✨ AI 推荐玩法」 | 输入人数和偏好，推荐剧本杀/桌游/狼人杀方案 |
| 活动详情「✨ AI 活动小记」 | 根据报名、留言、照片自动写一段温暖小记 |

AI 使用**微信「小程序成长计划」免费额度**（10 亿 Token / 6 个月），云函数通过官方 SDK 调用，无需配置 API Key。

## 🔔 订阅消息

微信要求用户**主动授权一次订阅**，且一次授权只能发一条消息。本小程序：

- 登录时顺带请求订阅授权；也可在「我的 → 活动通知」再次开启
- 创建活动后，云端自动给圈内已授权的好友推送「新活动提醒」
- 点击消息直达活动详情（跨设备也有效，使用云端 ID 定位）

## 🔐 隐私与合规

- **登录协议主动勾选**：登录页需手动勾选《用户服务协议》与《隐私政策》，不默认同意
- **游客可先浏览**：打开小程序直接进首页看示例活动，发起/报名/留言/传照片时才引导登录
- **内容安全**：活动标题、介绍、留言、昵称、AI 输入输出在保存前都经微信 `msgSecCheck` 校验
- **位置信息**：仅用户主动「地图选点」时使用；`app.json` 已声明 `chooseLocation`
- 头像昵称使用微信官方「头像昵称填写能力」，无需额外授权弹窗

> 提审前请在公众平台完成：申请 `wx.chooseLocation` 位置接口权限、配置《用户隐私保护指引》（位置/相册/头像昵称）、核对订阅消息模板字段。
