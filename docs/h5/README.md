# Paddy小助手 · 网页版（完整功能）

小程序合规版（工具-预约/报名类目）不包含的**活动相册、留言、AI 小记**，由这个网页版承载——网页不受小程序服务类目限制，功能一个不少，数据与小程序共用同一个云环境。

## ⚠️ 重要：网页放哪里？

**不要依赖 GitHub Pages 给国内朋友用。** github.io 在国内访问时好时坏（不同运营商、时段差异很大，手机流量更容易被重置），只适合海外访客。

国内用户请部署到**云开发静态网站托管**（和云函数同一个环境，腾讯国内节点，稳定快速）：

```
https://<你的环境ID>.tcloudbaseapp.com
```

## 部署步骤

### 1. 开启匿名登录（云开发控制台）

进入云开发控制台 → 环境 → **登录授权**，开启「**匿名登录**」。

### 2. 开通静态网站托管并上传页面

云开发控制台 → **静态网站托管** → 开通（有免费额度）→ 把本目录的 `index.html` 上传到根目录。

开通后访问地址形如：

```
https://wechatminiprogram-d1d9q1d1ae383e.tcloudbaseapp.com/index.html
```

### 3. 配置 Web 安全域名

云开发控制台 → 环境 → **安全配置 → Web 安全域名**，添加网页所在域名，例如：

```
https://wechatminiprogram-d1d9q1d1ae383e.tcloudbaseapp.com
```

### 4. 部署 h5api 云函数

微信开发者工具里，对 `cloudfunctions/h5api` **右键 → 上传并部署：云端安装依赖**。

数据库集合 `h5_extras` 会在第一次调用时自动创建。

## 使用

打开网页（本目录的 `index.html`），输入圈子通行码即可查看活动、上传照片、投票、留言、生成 AI 小记。

通行码与小程序加入圈子用的是同一套，数据完全互通。

> GitHub Pages 上的副本（`/paddy-helper/h5/`）仅作海外访问备用，国内请用上面的 tcloudbaseapp.com 地址。
